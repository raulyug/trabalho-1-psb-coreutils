# Trabalho 1 - Programacao de Software Basico

Estudo de caso dos utilitarios `wc` e `tail` do GNU Coreutils para a
apresentacao em video do Trabalho 1 da PUCRS.

## Escopo

O trabalho analisara somente as evidencias necessarias para atender aos
criterios de avaliacao do enunciado. Nao e uma analise completa dos dois
programas.

## Codigo selecionado

- `src/wc.c`
- `src/tail.c`

A versao original e o commit fixado estao documentados em
[UPSTREAM.md](UPSTREAM.md).

> Estes arquivos pertencem ao projeto GNU Coreutils. Os cabecalhos originais
> de copyright e licenca foram preservados.
